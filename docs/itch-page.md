## Short description / tagline

Outlast the swarm in this WebGL2 arena roguelike.

## Description

**Swarm Survivors** is a Vampire Survivors-style horde survival game rendered with a custom WebGL2 engine — every enemy, projectile, particle, and damage number drawn in a single instanced draw call.

Survive 10 minutes of escalating swarms. Level up, draft from 10 weapons across 4 mechanics (projectiles, auras, orbit blades, novas), stack upgrades, and slay the **Hive Tyrant** when it rises at 10:00.

- 16 enemy types across a 12-wave escalating timeline
- 10 weapons × 8 levels + stat upgrades via 3-card level-up drafts
- Bloom post-processing, particles, screen shake, hit-stop
- Live performance overlay: FPS, frame timings, heap, GPU info
- Custom zero-dependency TypeScript → WebGL2 engine (~14KB gzipped)

## Controls

- **WASD / Arrow keys** — move (weapons fire automatically)
- **ESC** — pause
- **F11** — fullscreen
